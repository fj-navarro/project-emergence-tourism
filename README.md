# Emergence in Tourism Systems

Research on how tourism-system configurations emerge, evolve and propagate consequences through interconnected actors and places.

## Document

Rethinking the Analytical Foundations of Tourism Systems Research: An Emergence–Diffusion Framework for Policymaking, by Francisco J. Navarro-Meneses (Nebrija University).

- Original Word document: retained unchanged in this repository.
- Web source: index.qmd, with five extracted figures and the original comparison table.
- The submission cover sheet is excluded from the public web document. No journal publication or project funding is claimed.
